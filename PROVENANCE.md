# Provenance (original code)
All code in `psn/` and `psn_nodes/` was written from the owner's specs and the design notes in the Parametric Studio knowledge base (section 42 guide, node specs, security deep dive). No third-party source code was copied, ported or closely paraphrased.

| component | design idea from | licence of that source | what we took |
|---|---|---|---|
| `psn/expr.py` safe evaluator | `yanhuifair/ComfyUI-FairLab` (whitelist AST evaluator, no code execution) | MIT | the idea only (walk a whitelisted AST instead of calling eval); no code |
| `psn/sandbox*.py` | `Duanyll/comfyui_functional` (opt-in switch for unsafe code) and the Oct 27 audit of 12 "run a Python string" packs | not reviewed for reuse | the lesson: default-deny, explicit opt-in; no code |
| `psn/orchestration.py`, `psn/graph.py`, `PSN_Branch`, `PSN_QualityGate`, `PSN_AttemptPlanner` | ComfyUI's lazy-evaluation convention (`check_lazy_status`) and the section 17/28 pack surveys | GPL-3.0 (ComfyUI core) for the convention only | the public node API shape; no ComfyUI code is included |
Rules: the repo is AGPL-3.0-or-later (see LICENSE); bundled third-party code is listed with its licence in THIRD_PARTY_NOTICES.md; third-party packs stay optional extras; record every new inspiration here.

Subagents (psn/subagents, psn_nodes/subagents.py): original code written 2026-10-29; no third-party code.

psn_nodes/gen/ (section 44 batch, merged 2026-10-30): written by the local Qwen3.8-27B node factory from our own knowledge-base specs (no third-party code), tests written alongside.
Reviewed by Claude before merge: static scan for eval/exec/network/subprocess/file writes (clean); n_4 metadata encryption was replaced (the generated repeating-key XOR with a built-in key
was not encryption) by scrypt + Fernet, no default key.

psn_nodes/latent.py (12 torch-backed latent nodes, 2026-10-30): original code written by Claude for this project; tested on CPU tensors. Replaces the factory's section-24 latent modules, which only handled plain lists
(their docstring says tensor conversion is "out of scope") and so could not run on a real LATENT; those were not merged.

studio/worldkit/ (World Kit, ported 2026-11-01): the founders' own code from their earlier studio (an internal Apache-2.0 repository), relicensed here under AGPL-3.0-or-later by its authors, with the job flow, safety layer, UI and tests rewritten for this studio by Claude. No third-party source code is included. Third-party tools it can run (SAM 3D Objects, SkinTokens, AutoRemesher, Kimodo, a Blender retarget script) stay in their own folders, are started as subprocesses and are never imported or redistributed; studio/worldkit/data/soma77_slots.json is the founders' own bone map. workflows/worldkit_cutout_api.json and workflows/worldkit_body_photo_api.json use ComfyUI core nodes only. textures.procedural() is original code.

studio/vset/ (Virtual Set, ported 2026-11-01): the founders' own code from their earlier studio (an internal Apache-2.0 repository), relicensed here under AGPL-3.0-or-later by its authors, with the job flow, the safety layer, the model mapping, UI and tests rewritten for this studio by Claude. This includes studio/worldkit/blender_scripts/vs_scene.py, studio/web/virtualset.js and studio/web/vset_helpers.js. No third-party source code is included. workflows/vset_keyframe_edit_api.json, vset_h3_union_api.json, vset_h3_motion_api.json and vset_wan22_funcontrol_api.json are the founders' own graphs; they use ComfyUI core nodes, plus third-party node packs only by name (MiniMaxH3FunUnion2LoaderEXPT8 and MiniMaxH3FunUnion2ApplyEXPT8 from comfyui-minimax-h3-audio-T8, VRAM_Debug from ComfyUI-KJNodes in the motion graph), which are never bundled. The OpenPose limb order and colours in studio/vset/passes.py are the published BODY_18 convention, recorded as data. workflows/vset_ltx25_layout_api.json is written in API form by Claude from the settings in Lightricks' published LTX-2.5 Layout to Render workflow and card (sampler, sigmas, frame positions); the weights are never bundled and carry the LTX-2.x Community License.
Music 3 style library (studio/music3_styles.json, studio/music_styles.py, studio/web/music_styles*.js, scripts/build_music3_styles.py): ported from the founders' own earlier studio, which was Apache-2.0; the founders relicense their code here as AGPL-3.0-or-later. Two kinds of data are in the file. The official styles come from MiniMax's caption-rewriter library and keep the MiniMax-Music3 Community License (see THIRD_PARTY_NOTICES.md). The styles with `source: "studio"` were written by the earlier studio, are marked studio-authored and untested, and nothing has been rendered from them.

Recipe library (studio/recipe_library/, studio/lora_recipes.json, studio/recipe_check.py, the library parts of studio/recipes.py, studio/loras.py and studio/web/recipes.js, ported 2026-11-01): the picture templates, shot lists, loop and timelapse presets, stylizer instructions, sound recipes and LoRA settings notes are the founders' own work from their earlier studio (an internal Apache-2.0 repository), relicensed here as AGPL-3.0-or-later by their authors; the runner, the checks and the page were written for this studio by Claude. Adult material, real-person likeness LoRAs, persona names and private notes were left out. No LoRA weights are included: lora_recipes.json is settings and prompt notes that the earlier studio read from each LoRA's own public card, each row records that LoRA's licence as far as it is known, and rows marked unverified or non-commercial say so. Every entry keeps the proof level the earlier studio recorded; nothing there has been rendered in this studio yet.
studio/sound/ (dsp.py, synth.py, chains.py, render.py): the founders' own procedural sound code from the same earlier studio, relicensed AGPL-3.0-or-later by its authors; render.py is rewritten for this studio. numpy only, no samples, no third-party code.
Node audit (2026-11-01): every node was read and labelled. 156 generated nodes implied work they did not do or fabricated results: 34 were removed, 98 renamed to say what they are (their fabricated outputs dropped), and 24 made real. tests/test_node_honesty.py stops fabrication markers coming back. The earlier "reviewed before merge" scan looked for unsafe code, not for honest results.

RES4LYF page (studio/web/res4lyf*, docs/res4lyf/, scripts/build_res4lyf_page.py, res4lyf_graphs.py, res4lyf_node_check.py): original notes in our own words with short credited quotes, no pack code; renders made on a separate ComfyUI, never shipped with the pack.

Sampling Lab (studio/sampling_lab*, studio/web/samplinglab*, scripts/build_sampling_*.py, scripts/sampling_lab_renders.py, 2026-11-01): original code. The atlas data holds facts and equations in our own words, read from ComfyUI core and third-party node packs, each credited with its licence as found; no pack code or README text is bundled, and pack code was parsed as text, never run, to build it. The sigma lists and solver numbers are computed by ComfyUI's own functions. The JPEGs in studio/web/sampling_lab are renders made here with ComfyUI core nodes and the checkpoints named in renders.json, under those model licences.
